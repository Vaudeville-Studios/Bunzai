# Create a character with the Table Read

Open **The Table Read** from the app navigation, or choose **Table Read** beside New character in
the Library. Blank character creation still works as before.

## Choose the pace and the model

- **Cold Read** asks a few useful questions, aiming for about five and stopping by eight.
- **Deep Dive** follows gaps and contradictions, with a finite limit on follow-up questions.
- **Rapid Fire** prepares its choices first, then starts a 90-second round. It accepts only the
  displayed choices. When time is up, you choose whether to review or ask the interviewer to finish.

Choose a model from your existing saved connections. If none is available, **Open Connections**
takes you to the connection settings. Your idea, answers and this character draft go to that model;
other Library pieces are not included. The connection's normal provider charges can apply.

Write what you already know: a name, a premise, a scene, a conflict. The Understudy uses that as the
starting point rather than asking you to fill every field from scratch.

## Answer and take the pen

In Cold Read and Deep Dive you can choose a quick answer or write your own. **Keep this answer**
stores it before the interviewer works on the next question. The living card updates with validated
proposals as turns finish; it does not pretend to stream fields before they can be read safely.

Choose **Edit** beside any card field, change it, then **Keep edit**. The field is marked **Your edit**
and later model proposals cannot replace it. You can deliberately keep a field blank. Text still
inside an open field editor has not been kept yet; finish or cancel that edit before leaving.

On a narrow screen, use **Interview** and **Living card** to switch panes. Both show the same draft.

## Pause, recover and review

Your accepted answers and kept edits live in the encrypted library. Reopening Table Read resumes the
one saved interview. Loading or refreshing it does not ask the model another question.

**Stop** interrupts a running model request while keeping the accepted work. If a connection fails,
you can retry explicitly, edit the card, or choose **Review current draft**. A request that may still
belong to another device must be stopped or reach its deadline before retrying.

There are two ways to review:

- **Review current draft** uses the fields already on the card, without another model call.
- **Finish with the interviewer** asks the selected model to bring your accepted answers together.

Review lists fields that are still empty. Model-written text is a draft to judge, not a guarantee
that every detail is correct. You can edit it before saving.

## Save and continue in the Workbench

Give the character a name, then choose **Save character**. Only this action creates a Library card.
If a save is interrupted, **Retry saving** recovers the same character identity instead of making a
second copy. While that save is unresolved, the interview stays frozen to protect the reviewed draft.

After saving, **Open character** takes you to the normal Workbench editor, where you can add art,
expand the character or export it. Starting another Table Read clears the interview, not the saved
Library character.

Use encrypted Library backups to retain interview progress. Exporting the finished character carries
its normal character fields, not the interview conversation. This version creates one character;
it does not also create a lorebook or a player persona. Table Read is unavailable in the temporary
browser-only Studio.
