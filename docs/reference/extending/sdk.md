## Host invocation context

`bunzai.context.invocation.resources` is a read-only array of at most 16 host-selected `{kind,id}` refs. The host supplies it separately from command input; it does not grant access. Each operation still requires an exact matching grant. Desktop and Browser command menus attach staged or active pieces. Terminal has no current-piece selector; use explicit operation resource selectors where supported.
