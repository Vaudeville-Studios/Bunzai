StateStore and verified that old known-key settings reads/writes preserve the new private row:
`old-reader-proof.ts` and `old-reader-proof.stdout.log` in the task profile, exit 0. The older build
has no Table Read interface, rather than a new incompatible SQL shape.

The original detector and its eighteen runtime-schema assertion remain intact; no rollback fence
